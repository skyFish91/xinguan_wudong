# 住模块（民宿预订）文件清单

> 来源项目：乌东文旅"衣食住行"综合服务平台（V1.0）
> 整理日期：2026-09-10

## 一、本文件夹内容（住模块专属文件）

| 文件 | 职责 |
| --- | --- |
| `server/src/entity/hotel.entity.ts` | 3 个数据库实体：民宿主表 t_homestay、房型 t_room_type、房态库存 t_room_inventory |
| `server/src/module/hotel/hotel.module.ts` | 核心业务与接口：民宿列表筛选、详情、房价日历查询、房型选择、预订下单（Service + Controller） |
| `server/src/module/hotel/hotel.admin.ts` | 商家端管理接口：民宿上架、房型与房态维护 |
| `server/test/hotel.service.test.ts` | 单元测试 12 个用例（民宿查询、房价日历、房态扣减等） |
| `web/src/views/hotel/List.vue` | 游客端民宿列表页（筛选、民宿卡片） |
| `web/src/views/hotel/Detail.vue` | 游客端民宿详情页（房价日历、房型选择、预订按钮） |
| `admin/src/views/merchant/Hotel.vue` | 管理后台商家民宿管理页（房型、房态、订单） |
| `sql/住模块-建表.sql` | 4 张表的建表语句，原样摘自项目 sql/01-ddl.sql（t_homestay 第 454 行、t_room_type 第 478 行、t_room_inventory 第 495 行、t_hotel_booking 第 179 行） |
| `sql/住模块-种子数据.sql` | 民宿、房型、房态库存的种子数据，原样摘自项目 sql/02-dml.sql（第 134 行起） |
| `images/homestay-1.svg`、`homestay-2.svg` | 民宿封面图（列表页与详情页主图） |
| `images/room-1.svg` 至 `room-6.svg` | 客房示例图 |

## 三、说明

1. 本文件夹按原项目相对路径组织，文件内容与项目完全一致（SQL 为原样截取，未改动）
2. 住模块运行依赖：MySQL 中的 t_homestay / t_room_type / t_room_inventory / t_hotel_booking 四张表，以及订单中心、用户体系等公共能力
3. 图片原位置：项目 server/uploads/seeds/ 目录
