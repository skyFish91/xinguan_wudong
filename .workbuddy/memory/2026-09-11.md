### ① 「顿一下」的真正根因（本次最有价值）
不是动画时长问题，是**导航还占着 68px 文档流**：
- 原状：`.nav` 是 `position: sticky`（占流）+ App.vue 用 `setTimeout` 延迟 **200ms** 才卸载导航
- 而 `mode="out-in"` 换页在 **160ms** 就完成（wd-page leave 0.16s）
- 结果：登录页先带着导航渲染 → 被顶下去 68px → 40ms 后导航卸载 → **弹回原位** = 肉眼看到的"顿一下调整到正确位置"
- 第二个成因：`wd-auth` 用 `scale(1.012)` 缩放**整屏 100vh 元素** → 溢出视口 → 滚动条闪一下 + 内容横抖

**修法（关键：让导航彻底不占流，而不是调定时器）**
- `.nav` 改 `position: fixed`（TopNav.vue），新增令牌 `--wd-nav-h: 68px`
- App.vue 用 `<div class="app-content">` 包住 router-view，`padding-top: var(--wd-nav-h)` + `min-height: 100vh`（后者防止 out-in 换页瞬间文档高度塌陷露底）
- **删掉 navTimer，`showNav` 改成 `computed(() => !route.meta.bare)`** —— 显隐与布局彻底解耦后，延迟就没有存在意义了
- `wd-auth` 改成**只淡入淡出**（0.34s），不再缩放
- 整屏面板用**等量负 margin 抵消** padding：`AuthShell` 的 `margin-top: calc(-1 * var(--wd-nav-h))` → `padding(68) + (-68) + 100vh = 100vh`，正好一屏且不跳
- `AuthShell` 加 `position: relative; z-index: 300` 压住 `z-index: 200` 的固定导航，否则导航退场 0.2s 会在登录页顶部擦一道
