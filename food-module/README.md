# 模块二：食——餐饮美食模块（独立可运行版）

> 本文件夹是「食」模块的**独立可运行项目**，前端页面已精简为纯"食"，后端保留了支撑"食"运行的必要模块（订单/登录/购物车/支付）。

## 一、目录结构

```
food-module/
├── start.bat          # 一键启动（Windows）
├── install.bat        # 首次安装依赖
├── fake-redis.js      # 内存版 Redis（本机无 Redis 时用）
├── sql/food.sql       # 食模块建表 + 种子数据
├── web/               # 前端（Vue3 + Element Plus，精简为纯食）
│   └── src/
│       ├── views/food/          # 食页面（3 个）
│       ├── views/trade/         # 购物车/订单/支付（食的加购/预订需要）
│       ├── views/Login.vue / Register.vue
│       ├── components/TopNav.vue  # 精简导航
│       └── router / api / stores  # 基础
└── server/            # 后端（Midway + TypeORM）
    └── src/
        ├── module/food/   # 食模块（用户端 + 商家端）
        ├── module/order/  # 统一订单（餐位预订依赖）
        ├── module/auth/   # 登录
        ├── module/cart/   # 购物车
        ├── module/pay/    # 支付
        └── entity/        # 实体（含食新增的评价/收藏/人均价）
```

## 二、启动步骤

1. **建库建表**：确保 MySQL 有 `wudong` 数据库，执行 `sql/food.sql`（含食的表和种子数据）。
2. **安装依赖**：双击 `install.bat`（或在 `web/`、`server/` 下分别 `npm install`）。
3. **启动**：双击 `start.bat`，自动启动 Redis、后端、前端，并打开浏览器。
   - 前端：http://localhost:5173
   - 后端：http://127.0.0.1:7001

> 默认数据库密码为 `root`，如不同请改 `start.bat` 里的 `DB_PASSWORD`。

## 四、页面功能

**苗乡餐厅 · 餐位预订**
- 餐厅列表：搜索、评分/容纳人数/**人均价格**排序
- 餐厅详情：菜品、餐位预订（提前 2 小时）、**收藏**、**评价**（发表/列表）、人均价格

**苗乡特产 · 农产品**
- 分类筛选、搜索、排序（销量/价格）
- 农产品详情大图页：富文本详情、规格、**加购物车**、**立即购买**、**收藏**、**评价**

**业务规则**
- 餐位预订提前 2 小时；取消政策（24h 前免费取消，24h 内提示 50% 违约金）

## 五、本次新增功能（相对原"食"代码）

1. 实体：`t_food_review`（评价）、`t_food_favorite`（收藏）、餐厅 `avg_price`（人均价格）
2. 用户端：餐厅价格排序、收藏、评价、立即购买、农产品详情大图页
3. 商家端：分类管理（增删改查）、评价管理（列表/回复/隐藏）、TOP 菜品统计
4. 业务规则：餐位预订取消政策

> 说明：美食地图、餐厅位置地图、距离排序本次搁置（工作量大，后续再做）。

## 六、技术说明

- **后端保留必要模块**：食的餐位预订复用统一订单（`order`），登录复用 `auth`，加购复用 `cart`，支付复用 `pay`。其余业务模块（衣/住/行/社区等）已删除。
- **公共文件改动**（本文件夹内已含改后版本；如需同步回原项目，对应改动如下）：
  - `server/src/middleware/auth.guard.ts`：修复鉴权，游客可浏览食数据。
  - `web/src/router/index.ts`：追加农产品详情路由。
- **图片**：SVG 占位图已替换为 Wikimedia Commons 免费图片（17 张），位于 `server/uploads/seeds/`。
