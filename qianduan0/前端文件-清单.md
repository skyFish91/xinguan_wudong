# 前端文件清单

> 来源项目：乌东文旅"衣食住行"综合服务平台（V1.0）
> 整理日期：2026-09-10
> 说明：项目共两套前端，本文件夹按原项目相对路径完整复制（未含 node_modules 依赖目录、dist 构建产物与运行日志）

## 一、游客端 web/（日常访问 http://localhost:5173/）

| 文件 | 职责 |
| --- | --- |
| `package.json` / `package-lock.json` | 依赖清单（Vue 3、Element Plus、Pinia、Vite 等） |
| `vite.config.ts` | 构建配置（含 /api 与 /uploads 反向代理到后端 7001） |
| `tsconfig.json` | TypeScript 配置 |
| `index.html` | 页面入口 |
| `nginx.conf` / `Dockerfile` / `.dockerignore` | 容器部署配置 |
| `src/main.ts` | 应用入口（挂载 Vue、Element Plus、Pinia、路由） |
| `src/App.vue` | 根组件 |
| `src/router/index.ts` | 全部页面路由与登录守卫 |
| `src/stores/user.ts` | 登录态（双 token 自动续期） |
| `src/api/request.ts` | axios 封装（统一错误码处理、401 跳登录） |
| `src/components/TopNav.vue` | 顶部导航栏（含购物车角标） |
| `src/views/Home.vue` | 首页（轮播、各模块推荐入口） |
| `src/views/Login.vue` / `Register.vue` | 登录 / 注册 |
| `src/views/clothing/List.vue`、`Detail.vue` | 衣：非遗商品列表、详情 |
| `src/views/food/Index.vue`、`RestaurantDetail.vue` | 食：餐厅列表、详情与餐位预订 |
| `src/views/hotel/List.vue`、`Detail.vue` | 住：民宿列表、详情（房价日历预订） |
| `src/views/travel/Scenics.vue`、`Routes.vue`、`RouteDetail.vue`、`Guides.vue`、`MyEtickets.vue` | 行：景区、路线、攻略、电子票 |
| `src/views/community/Feed.vue`、`PostDetail.vue`、`Publish.vue` | 社区：动态流、详情、发帖 |
| `src/views/trade/Cart.vue`、`Orders.vue`、`Pay.vue` | 购物车、订单中心、模拟支付 |
| `src/views/user/Profile.vue`、`MerchantApply.vue` | 个人中心、商家入驻申请 |

## 二、管理后台 admin/（访问 http://localhost:8082/）

| 文件 | 职责 |
| --- | --- |
| 工程配置 | `package.json`、`vite.config.ts`、`tsconfig.json`、`index.html`、`nginx.conf`、`Dockerfile`、`.dockerignore` |
| `src/main.ts` / `App.vue` | 入口与根组件 |
| `src/router/index.ts` | 后台路由与权限守卫（管理员/商家角色区分） |
| `src/stores/user.ts` | 后台登录态 |
| `src/api/request.ts` | axios 封装 |
| `src/views/Login.vue` | 后台登录 |
| `src/views/Layout.vue` | 后台整体布局（侧边栏、顶栏，按角色显示菜单） |
| `src/views/Dashboard.vue` | 数据看板 |
| `src/views/Users.vue` | 用户管理 |
| `src/views/Content.vue` | 社区内容审核 |
| `src/views/Sensitive.vue` | 敏感词管理 |
| `src/views/Ops.vue` | 运营配置（轮播、佣金规则） |
| `src/views/Orders.vue` | 订单管理（按类型查看、核销） |
| `src/views/Refunds.vue` | 退款处理 |
| `src/views/Finance.vue` | 佣金记账 |
| `src/views/Applies.vue` | 商家入驻审核 |
| `src/views/merchant/Clothing.vue` | 商家端：衣（商品与 SKU 管理） |
| `src/views/merchant/Food.vue` | 商家端：食（餐厅、餐位管理） |
| `src/views/merchant/Hotel.vue` | 商家端：住（民宿、房态管理） |
| `src/views/merchant/Travel.vue` | 商家端：行（门票、路线管理） |

## 三、本地运行（如在自己电脑跑）

```bash
cd web && npm install && npm run dev     # 游客端 http://localhost:5173/
cd admin && npm install && npm run dev   # 管理后台（端口见 vite.config.ts）
```
